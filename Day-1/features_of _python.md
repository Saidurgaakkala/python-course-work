### OOPS concept(object oriented programming language)

OOPS is a writing a programs using objects and classes

for example:

car-object

car design-class

1. ## class:

A class is a blueprint(design)

ex:car design is a class

## 2.object:

An object is a real instance of a class

ex:mycar,your car=object

## 3.Encapsulation:

wrapping data and methods into a single unit.

protect data from direct access.

Access through methods only.

## 4.Abstraction:

Hide unnecessary details.

show only important things.

## 5.Inheritance:

one class gets properties of another

parent-child

## 6.polymorphism:

same function different behaviour

## real world examples:

class-mobile design

object-your phone

encapsulation-password protection

abstraction-you use apps,not internal circuits

inheritance-smart phone from basic phone

polymorphism-same button different actions
